Este repositório documenta minha jornada de estudos baseada no plano de 12 semanas para me tornar um desenvolvedor Full-Stack, utilizando os recursos gratuitos da DIO.

## 🎯 Objetivo
Transformar-me em um desenvolvedor Full-Stack capaz de integrar tecnologias de Front-end, Back-end, Banco de Dados e Cloud. O plano foi desenhado para ser executado com constância (2h/dia) ao longo de aproximadamente 4 meses.

## 📚 Curadoria de Fontes
Utilizei os seguintes guias como base para o meu NotebookLM:
1. **Plano de Estudos DIO (Full-Stack + Cloud + Banco de Dados)** - Conteúdo consolidado do roteiro de 12 semanas.
2. **Roadmap.sh (DevOps)** - Referência para melhores práticas em integração contínua e cloud.
3. **Documentação Oficial (MDN, Node.js, AWS)** - Fontes técnicas primárias para consulta durante a prática.

## 🧠 Engenharia de Prompts e Cicatrizes
*   **Prompt 1 (Visão Geral):** "Com base no cronograma de 12 semanas, crie uma tabela de atividades diárias para uma semana focada em React, priorizando a prática em vez da teoria."
    *   *Resultado:* O NotebookLM gerou um cronograma equilibrado com 30 min de teoria e 1h30 de codificação.
*   **Dificuldade (Cicatriz):** O NotebookLM apresentou dificuldade em sugerir projetos práticos que integrassem Docker com AWS de forma simples para um iniciante.
    *   *Solução:* Refinei o prompt para: "Atue como um mentor DevOps e simplifique a implementação de um deploy com Docker e AWS, focando apenas no nível gratuito (Free Tier)".

## 📖 Miniguia de Estudo (Resumo Consolidado)

### 📝 Resumo do Cronograma
O plano é dividido em módulos de 20 horas, totalizando 170 horas de carga horária para:
- **Fundamentos & Git:** Base para versionamento.
- **Frontend:** HTML, CSS, JavaScript e React.
- **Backend:** Node.js e Express.
- **Banco de Dados:** SQL (PostgreSQL) e NoSQL (MongoDB).
- **Cloud & DevOps:** AWS e CI/CD com GitHub Actions.

### 📕 Glossário de Conceitos
*   **Full-Stack:** Profissional capaz de atuar em todas as camadas da aplicação (Client-side e Server-side).
*   **CI/CD:** Pipeline de integração e entrega contínua que automatiza o deploy.
*   **CRUD:** Operações básicas (Create, Read, Update, Delete) em bancos de dados.

*   "Explique como o conceito de [git] se aplica a um cenário de e-commerce real."
